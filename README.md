# SkillRoute Homebrew Tap

## How do I install these formulae?

```bash
brew install erichare/skillroute/skillroute
```

Or:

```bash
brew tap erichare/skillroute
brew install skillroute
```

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "erichare/skillroute"
brew "skillroute"
```

[SkillRoute](https://github.com/erichare/skillroute) is a local-first skill
catalog and router for agent builders.

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
